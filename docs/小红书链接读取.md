# 小红书笔记链接读取方案

本项目默认使用**免费、自托管的 Playwright 浏览器采集器**读取用户分享的单条笔记，并对门店名称、位置、人均进行来源核对。参见 [本地小红书采集器](本地小红书采集器.md)。TinyFish 仅作为之前的实验性核实工具，不是必需依赖。

## 标准流程

1. 解析用户提供的 `xhslink.cn/o/...` 短链接，跟随跳转并获得笔记 ID。避免将完整跳转网址中的个人分享参数、令牌或 Cookie 提交到仓库。
2. 通过仓库中的 tools/xhs_collector.py 打开浏览器，使用用户自己登录的本机资料读取可见标题、正文和页面信息，图片按轮播逐张截图。
3. 自动点击下一张直至轮播结尾，进入评论区，逐步滚动、展开回复，并尝试点击评论图片保存预览；生成 manifest.json 与压缩包。由我审核采集包中的杯身、商家招牌、定位标签、作者答复。
4. 对店名、地址和营业时间，优先检索商场/品牌官方商户目录；评论区的模糊位置只当线索，不擅自指定城市、行政区、楼层或铺位。
5. 单品售价、人均必须基于具体店铺的菜单、商家平台或可靠消费记录，**不把其他产品的参考单价当成人均**。
6. 按笔记 ID 去重，更新 `notes/`、`data/notes/` 与首页索引。无法核实的数据保留 `null` 并记录原因。

访问受限时可使用用户自主授权的已登录浏览器会话；不绕过访问控制、不存储账户密码或 Cookie，也不把用户的私密浏览资料写入公开仓库。

## 技术参考

- [Playwright（免费）](https://playwright.dev/python/)：用于本地用户授权浏览器操作，是本仓库默认方案。
- [TinyFish（付费可选，非依赖）](https://agent.tinyfish.ai)：仅曾用于首条笔记核实。
- [ucmao/media-parser：小红书解析说明](https://github.com/ucmao/media-parser/blob/main/docs/parsers/xiaohongshu.md)：介绍短链重定向、SSR 初始状态与前端差异，非官方 API，可能随平台更新失效。
- [NEORUAA/XHS_Downloader_Android](https://github.com/NEORUAA/XHS_Downloader_Android)：利用用户本人登录的 WebView 收集笔记的参考实现。
