# 小红书笔记链接读取方案

本项目收到分享短链后，采用**优先实际读取、其次交叉核实、最后保留待核实字段**的流程。

## 读取流程

1. 提取 `xhslink.cn/o/...` 或 `xhslink.com/...` 等有效分享 URL。
2. 允许 HTTP 跳转，解析小红书网页 URL 和唯一笔记 ID；为后续读取保留页面原有的必要查询参数（例如 `xsec_token` 与 `xsec_source`），不要只拼接笔记 ID。
3. 尝试读取公开可访问的网页内容。社区技术方案中，笔记详情有时存在于页面的 `window.__INITIAL_STATE__`；可按移动端、桌面端 User-Agent 的兼容情况切换。
4. 如果页面要求登录、验证码或其他访问校验，应使用用户授权登录的浏览器会话；不在 GitHub 仓库保存 Cookie 或账号数据，不绕过访问控制。
5. 如果取得正文及地点，优先找作者标注的商家名称、位置标签和套餐/菜单信息，再与地图/商家公开页面核对门店及价格。
6. 访问失败时，使用用户截图中可见信息建立“部分核实”档案；明确未知字段。后续有可靠信息再补全，而不是自动猜测。

## 已研究的实现参考

- [ucmao/media-parser：小红书解析说明](https://github.com/ucmao/media-parser/blob/main/docs/parsers/xiaohongshu.md)：介绍短链重定向、SSR 初始状态和不同端的兼容问题。这是第三方项目的技术说明，非官方 API，是否可用取决于小红书当前网页行为。
- [NEORUAA/XHS_Downloader_Android](https://github.com/NEORUAA/XHS_Downloader_Android)：提供在本机登录的 WebView 中提取文案、保存笔记信息的思路，适合网页普通读取受限时由用户自己授权使用。
