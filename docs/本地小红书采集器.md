# 免费小红书图文与评论采集器

## 功能与成本

使用开源 [Playwright](https://playwright.dev/python/) 在你自己的 Windows / macOS / Linux 电脑上打开浏览器，不需要 TinyFish、商业爬虫 API 或付费 AI API。

程序按浏览器可见界面执行：
1. 打开**你明确指定的一条笔记**（支持小红书短链接及分享文案）。
2. 依次点击轮播图的“下一张”，每张截图存入 gallery。
3. 读取笔记标题、正文、作者（DOM 页面结构允许时）。
4. 在评论区域自动展开“更多回复”、向下滚动、采集可见文字并去重。
5. 遇到评论区带图的元素，尝试点击预览，将预览截图保存到 comment_images/images。
6. 输出结构化 JSON、审阅指南和 ZIP 证据包，供进一步视觉分析与核实。

不会自动点赞、发评论、发笔记、下载非公开数据或绕过登录/验证码。

## Windows 安装（一次）

前提：已安装 Python 3.11+ 且命令行可以调用 py 或 python。

下载本仓库（GitHub Code → Download ZIP 并解压，或用 Git 克隆）。在仓库目录双击：

    scripts\install_xhs_windows.bat

它将安装 Python Playwright 库与 Chromium 浏览器。之后在 PowerShell 中运行：

    python tools/xhs_collector.py --login-only

浏览器打开后由你自己登录小红书，完成时在终端按 Enter。浏览器个人资料默认保存在电脑用户目录中：

    ~/.guangzhou-food-guide/browser-profile

**不要把这个目录、cookies、浏览器状态上传到 GitHub 或聊天中。**

## 采集笔记

PowerShell / CMD（在仓库根目录执行）：

    python tools/xhs_collector.py "https://xhslink.cn/o/6fC6qdVSi8A"

如果第一次打开某些页面还需手动处理验证码：

    python tools/xhs_collector.py "https://xhslink.cn/o/6fC6qdVSi8A" --pause-login

或直接用 Windows 批处理：

    scripts\run_xhs_windows.bat "https://xhslink.cn/o/6fC6qdVSi8A"

本地会生成：

    captures/
      6af68ea9000000002b03d01b/
        YYYYMMDDTHHMMSSZ/
          manifest.json
          REVIEW.md
          gallery/
            01.png
            02.png
          comment_images/
            images/
              001.png
              002.png
        YYYYMMDDTHHMMSSZ.zip

- manifest.json：笔记 ID、标题、正文、可见评论及来源、图片相对路径、每一步的覆盖情况。
- gallery：从**可见轮播界面**保存的图片截图。
- comment_images：尝试点击评论配图后保留的预览截图。
- ZIP：将证据打包，可在 ChatGPT 上传；由我进一步识别、交叉核实，然后写入本仓库数据文件。

**当前是本地采集 + 上传证据包的流程**。尚不能仅通过在 ChatGPT 发送链接就远程控制你的电脑；若希望全自动，需要你在本机运行一个允许 ChatGPT 访问的受控服务/连接器，不能把浏览器登录资料放到公开仓库。

## 安全与准确性

- 此程序必须由用户在本机主动运行，仅针对你提供的笔记链接。
- 不是小红书官方 API；网页元素和登录策略变化时需要维护选择器。
- 大量评论可能是虚拟列表，DOM 里仅同时存在一部分评论。程序会逐段采集去重，但**不保证全部评论**。
- 如果按钮缺失、滚动到尾、访问受限、达到运行上限，会在 JSON 中写入停止原因；不会虚构“100%采集”。
- 默认最多尝试 30 张轮播图片、120 次评论滚动、80 张评论配图预览。参数可以按正常使用情况调节，例如：
  
      python tools/xhs_collector.py "链接" --max-photos 40 --max-scrolls 180 --max-comment-images 100

- 评论作者、评论时间、店名、地址、价格均可能由人输入，必须独立核实。不要将截图中的猜测直接当成已确认门店资料。
- 证据包含用户可见的第三方评论和图片，不要公开发布完整包；仓库 .gitignore 会排除 captures 和 .zip。
- 某些图片需要点开后才能取得清晰预览，若无法点击会在记录中标注；第三方评论图片应避免未经许可再发布。

## 自检与开发

静态检查：

    python -m py_compile tools/xhs_collector.py
    python -m unittest discover -s tests -v

测试使用本地模拟页面验证轮播、评论、去重等通用逻辑；实际小红书动态页面还必须现场回归验证。若现场失败，保留本地 REVIEW.md、manifest.json 中的覆盖信息，**不要上传包含账号私密资料的浏览器配置文件**。

设计依据：[Playwright Locator](https://playwright.dev/python/docs/locators) 与 [Playwright input/scroll](https://playwright.dev/python/docs/input)。
