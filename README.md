## 如何使用

- 点击收藏名称查看推荐理由、来源、核实状态及待补充信息。
- `data/notes/` 保存按笔记 ID 去重的机器可读 JSON，`notes/` 保存便于浏览的 Markdown。
- 同店多条推荐合并到同一门店档案之前，必须确认店名与分店；同一笔记不重复入库。
- 记录“想去 / 已去 / 推荐 / 不再考虑”，未亲自探店不代写个人评分。
- 餐厅所在行政区、商圈、地址、人均、营业状态都可留空待核实；变动时附核实时间与证据。
- 录入和更新要求见 [录入规则](docs/录入规则.md)。

> 首条收藏只由用户提供的笔记截图证实饮品与搭配。原小红书短链可解析出笔记 ID，但当前网页正文不能可靠读取。截图标题里的“妈嘟太好吃”是表达惊叹，不作为店名。
