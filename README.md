## 免费的小红书采集程序

已内置 [Playwright 小红书采集器](tools/xhs_collector.py)，**无需 TinyFish**。你可以在自己电脑上的浏览器登录一次，然后针对分享链接依次翻阅图片、展开/滚动评论并打开评论图片，自动导出 JSON、截图和 ZIP 证据包。

Windows 安装：双击 scripts/install_xhs_windows.bat；运行示例：

    python tools/xhs_collector.py "https://xhslink.cn/o/6fC6qdVSi8A" --pause-login

完整教程：[本地小红书采集器安装与使用](docs/本地小红书采集器.md)。

注意：项目已经包含程序和离线测试，但**尚未使用你的真实小红书登录会话完成端到端验收**；不同页面版本可能需要调整选择器。采集包保存在本机 captures/（Git 忽略），可上传本聊天由我审核并继续更新美食收藏；现阶段不能直接通过聊天远程操作你的私人浏览器。

## 使用方法

- 点击美食名称查看推荐理由、来源、核实状态及待补充信息。
- `data/notes/` 保存按笔记 ID 去重的机器可读 JSON，`notes/` 保存方便浏览的 Markdown。
- 同店多条推荐合并到同一门店档案之前，确认品牌和具体分店；同一笔记不重复入库。
- 记录“想去 / 已去 / 推荐 / 不再考虑”，未亲自探店不代写个人评分。
- 地址、价格和营业时间变化时更新核实日期与证据。
- 详见 [录入规则](docs/录入规则.md) 与 [小红书链接读取方案](docs/小红书链接读取.md)。

> 证据完整度因笔记而异。第一条曾通过 TinyFish 核查正文与部分评论；第二条根据用户提供的笔记摘要整理，并利用公开信息核实同名体育西店线索。第二条原链接的完整内容与具体门牌尚未独立读取，不冒充已抓取；两条均未填写未经证实的人均。
